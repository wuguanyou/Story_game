## 一、專案定位與故事世界（PDF 第 1–2 頁）

- **名稱**：《植心溫室》
- **類型**：文字劇情 × 時間管理 × 性格傾向塑型。
- **玩家角色**：新入職的「植心師」。
- **場景**：一座隱蔽療養院，患者的心理創傷會長成奇異植物。
- **主要任務**：在有限時間內安排治療、建立信任，照顧多位患者並承擔選擇後果。
- **核心目標**：平衡治癒與信任，讓治療結果和情感理解呈現不同層次。
- **故事提問**：「當你能治好一個人，卻未必能真正理解他，你會怎麼選？」
- **結局構想**：依治療成果與玩家行為呈現不同結局。

這些是**提案中提出的設定與目標**，不等同於正式劇情文本已交付。

## 二、設計動機（PDF 第 3 頁）

| 核心 | 提案構想 |
| --- | --- |
| 把創傷變得可見 | 以植物象徵心理創傷，透過外在變化呈現角色內心狀態。 |
| 治療不只有一種答案 | 將治癒率與信任值分開計算，呈現專業處置與情感理解可能不同步。 |
| 讓選擇承擔代價 | 每日行動點有限；玩家必須分配時間，也可能因忽略患者錯過重要事件。 |

**設計核心**：玩家如何照顧別人，也逐漸形塑自己。

## 四、提案設計步驟（PDF 第 5 頁）

1. **確認設定**：療養院背景、故事主題與核心角色。
2. **定義規則**：每日 5 AP、治癒率、信任值與 MBTI 傾向。
3. **編寫劇情**：角色事件、**滿月危機**與多種結局。
4. **製作原型**：把場景、選項、狀態與分支接成可玩流程。
5. **測試修正**：確認分支能抵達結局，調整數值與遊玩節奏。

> 提案寫的是「滿月危機」；現有後端實作的是「第 15 天強制事件」機制。**PDF 沒有明確說明兩者是同一事件**，是否對應仍需團隊確認。
